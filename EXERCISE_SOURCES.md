# Fontes de referência do catálogo de exercícios

O Constantia mantém um catálogo offline próprio, com nomes, classificação,
instruções curtas e erros comuns redigidos especificamente para o aplicativo.

Foram usadas como referências de cobertura/taxonomia:

- MuscleWiki — https://musclewiki.com/pt-br
- ExRx Exercise Directory — https://exrx.net/Lists/Directory
- ACE Exercise Library — https://www.acefitness.org/resources/everyone/exercise-library/
- hasaneyldrm/exercises-dataset — https://github.com/hasaneyldrm/exercises-dataset

O repositório `hasaneyldrm/exercises-dataset` declara licença MIT para código,
estrutura, dados e texto de instruções, mas contém uma exceção explícita para as
imagens e GIFs da Gym visual. Por isso, o Constantia **não incorpora** os
arquivos de mídia desse dataset nem copia imagens/GIFs das demais bibliotecas.

A biblioteca local é curada para substituição e planejamento, não uma importação
automática de milhares de movimentos. Exercícios complexos ou de maior risco não
entram automaticamente em fichas: podem existir no catálogo sem serem
prescritos pelo motor inicial.
