## Media exception

The source dataset's `images/` and `videos/` media is not included in Constantia.
Those files are © Gym visual and are explicitly excluded from the source MIT
license. The source repository states that cloning it does not grant a downstream
license to reuse the media. Constantia therefore keeps only `media_id` as a
future matching key for a separately licensed local media pack.

The original English exercise name is preserved. Portuguese display names are
used only where a conservative translation rule is available; otherwise the
source English name remains visible to avoid introducing unreliable exercise
nomenclature.
